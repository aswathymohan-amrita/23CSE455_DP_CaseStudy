# Design Pattern Case Study

This repository contains the team's case study on design patterns in an e-learning application. The complete, organized submission is in [`A11/DesignPattern_CaseStudy_Final/`](A11/DesignPattern_CaseStudy_Final/). The report and assignment brief are also available in [`A11/`](A11/).

## Submission files

- [`A11/DesignPattern_CaseStudy_Final/docs/CaseStudy_Report.pdf`](A11/DesignPattern_CaseStudy_Final/docs/CaseStudy_Report.pdf) — final report, including the five-member roster and the available findings from each study.
- [`A11/DesignPattern_CaseStudy_Final/docs/CaseStudy_Report.tex`](A11/DesignPattern_CaseStudy_Final/docs/CaseStudy_Report.tex) — editable report source.
- [`A11/DesignPattern_CaseStudy_Final/Part1/`](A11/DesignPattern_CaseStudy_Final/Part1/) — baseline analysis and pattern evidence.
- [`A11/DesignPattern_CaseStudy_Final/Part2/`](A11/DesignPattern_CaseStudy_Final/Part2/) — feature changes, source diffs, tests, and pattern evolution.
- [`A11/DesignPattern_CaseStudy_Final/Part3/`](A11/DesignPattern_CaseStudy_Final/Part3/) — cross-language Strategy and Observer examples and measurements.
- [`A11/DesignPattern_CaseStudy_Final/data/`](A11/DesignPattern_CaseStudy_Final/data/) — contains all excels
- [`A11/DesignPattern_CaseStudy_Final/Prompts/`](A11/DesignPattern_CaseStudy_Final/Prompts/) — available member prompt and chat records.
