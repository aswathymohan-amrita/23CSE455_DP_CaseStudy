## Instructions for Each Team Member:
1. Open your respective file above (`student1_prompts.md` to `student5_prompts.md`).
2. Copy **Prompt 1** and paste it into [ChatGPT](https://chatgpt.com), [Claude](https://claude.ai), or [Gemini](https://gemini.google.com).
3. In the same chat, copy and paste **Prompt 2**.
4. Generate a public shareable chat link:
   - In ChatGPT: Click the **Share** icon (top right) $\rightarrow$ **Copy Link**.
   - In Claude: Click **Share Chat** $\rightarrow$ **Copy Link**.
   - In Gemini: Click the **Share & Export** icon $\rightarrow$ **Share** $\rightarrow$ **Create public link**.
5. Paste the link into the `Public Chat History Link` field at the top of your file.
6. Commit and push the file to your team's GitHub repository.
